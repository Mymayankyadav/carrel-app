# A3 — Today screen, timer and distraction controls

## Completed (October 27, 2026)

- [x] **T1** The running timer's **Noticed** button now uses the desktop-only `kbd` class and has an explicit descriptive aria-label. Shortcut X no longer appears as a close glyph on touch phones. Other literal `<kbd>` references are in the Setup keyboard-shortcuts documentation, not actionable Today buttons.
- [x] **T2** When the running timer's note exactly equals its plan block title (after trimming), render the title in the plan metadata only. The Edit timer button remains available; distinct and blank session notes retain their editable field.
- [x] **T3** The existing Calendar-provided deadline chips display in one horizontally scrolling Today row with hidden scrollbars, non-shrinking buttons and truncation of excessively long titles. The responsive CSS rule belongs to the `day header` section; `web/cal.js` is unchanged.
- [x] **T4** Today Log and Where the day went are wrapped in native `details` with a semantic `summary`. The Log starts expanded and breakdown collapsed, saving changes in the existing `carrel.fold:log` and `carrel.fold:breakdown` settings via the `store` helper. The details wrapper is keyed to support live DOM morphing. `vLog`/`vBreakdown` (A5-owned) remain unmodified.
- [x] **T5** The Pomodoro ring SVG is an accessible progressbar with label and bounded percentage computed at render time.
- [x] **T6** Every study activity and life-activity switch button has an explicit `aria-pressed="true"` or `aria-pressed="false"`. Existing `.on` highlighted-state styling is preserved.
