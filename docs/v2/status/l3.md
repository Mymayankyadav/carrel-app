# L3 smart scheduler
Branch: `v2/l3`. Status: implementation and review.
Scope: deterministic history estimate, energy windows, 90%-capacity collision-free schedule, backwards deadline planning, Plan Auto-plan preview/Accept, partial backlog reconciliation, factor hints.
Tests: `web/test/sched_test.js` (median, clamps, min-count, windows, non-overlap, gaps, buffer, scheduling splits, deadline caps), `tools/v2_l3_smoke.py` (responsive mock preview and save).
Data safety: no new collections, all writes via `W()` and `commit()`, preserving Undo; accepts only explicit preview.
Known tradeoff: scheduling energy-window discovery uses observed hour-of-day averages; factor defaults to 1 without five completed plan-linked sessions.
