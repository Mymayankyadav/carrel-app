# L8 — Android surfaces (2026-10-28)
Owner: ORC / L8; draft PR #42; branch `v2/l8`.

## Built
- 2×1 and 4×1 DayNight widgets: activity/dot, elapsed system Chronometer, today's study projection and a 44dp Stop/Start-last control.
- Quick Settings tile: action label follows the cached native timer. Stop is a native queued RPC; Start launches Carrel via a deep link so that the existing offline-safe web write path performs the start.
- Android launcher: static **Quick add** and up to three dynamic subject shortcuts ranked by the web app's last 14 days of study minutes.
- `ACTION_SEND text/plain` + `app.carrel.study://capture` and `://start?act=...` deep links. Input uses Android `Uri.getQueryParameter`, is length-limited, and is stored privately until the authenticated web shell acks it. Shared text only opens Quick Capture; no task is automatically saved.
- Android 16 API-gated request for a promoted ongoing, silent timer notification; default existing notification on older Android. Suppressed when privacy is on.
- Widget and tile refresh on every native engine render, independent of notification permission.
- Added pure JVM deep-link regression tests and web bridge cold-start/allowlist tests.

## Deliberate integration choice
The existing native engine implements stop/break but has no native `carrel_start` RPC. Start-last therefore opens the already-authenticated app with a deep link; the web app creates the session via its existing queued write path, without adding a new DB function or unreviewed native mutation. Stop remains available with the app closed.
