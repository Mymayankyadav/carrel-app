# L5 Focus v2 — implementation handoff (2026-10-28)
Owner: ORC acting as L5; base includes L1 PR #35 and existing F1/L3/L4/L9.

## Implementation
- Pure Flowtime scheduling: `suggestBreak(focusMinutes)` clamps rounded focus/5 to 5–20 min. Countdown helper is deterministic, separately tested.
- Start sheet: expandable intention (80 chars), structured if/then (80 each), optional three-level energy field behind `energy` Labs flag (default off).
- ORC-owned core: optional fields are placed in the same atomic `state/current` set when starting; `entryFromCur` propagates them to the saved entry on stop/switch. Normalized entries retain fields. No extra writes or schema migration.
- Flowtime suggestion for non-Pomodoro study after 25 min; suggested break duration follows into break state and appears as a live countdown, including Focus mode.
- Three quiet break choices (Walk, Water, Stretch) for 10 seconds; choice updates the current break note using the existing undoable queue.
- Qualifying study stops (≥10 min) open an optional reflection sheet when `recall` Labs is on. Focus rating is required for Save; optional recall note is capped at 280 chars; topic IDs are validated against matching, non-archived topics.
- Reflection save commits the entry patch plus topic last-reviewed tags in one undoable write set. Topic due dates are *not* modified by tagging. Skip writes nothing.
- Labs defaults: `flowtime` on, `recall` on, `energy` off. The original one-tap rating remains available when recall is disabled.
- Existing Today, Focus, Start/Stop, v1 settings and Android notification paths are preserved.
