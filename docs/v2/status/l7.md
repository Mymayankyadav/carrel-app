# L7 Insights v2 — active implementation (2026-10-28)
Owner: ORC acting as L7. Following D9 in docs/PLAN-v2.md.

## Implemented
- Pure `advise(ctx)` with six ordered rules (behind, peak, estimate, reviews, drift, streak), bounded to three and week-specific dismissal via local storage.
- Pure `l7Accuracy` and flexible streak with one weekly freeze (only after a qualifying study day that week). Configurable minimum day 5–120 minutes, default 25.
- Insights dashboard retains S1 week/month date controls and stacked study chart. Adds weekly goal ring, action suggestions, 2-tap links to Subjects, Focus, Estimates, Patterns, Streak.
- Focus detail: rated-session average by hour and subject; Estimates detail: factor and accuracy; Streak detail: recent days with freezes.
- Fresh-start card on week start or 1st of month, with subject weekly goal sheet and existing `saveAct` writer.
- ORC-owned settings additions: `minDay:25` in DEFAULTS, stepper in Settings > Day, bounded `g2-nudge`.
- No external APIs, SQL migration, destructive user actions or Android permission changes.
